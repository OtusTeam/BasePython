# Шпаргалка: Основы HTML

## 🌐 Что такое HTML

**HTML** — язык разметки, который описывает структуру веб-страницы:

* заголовки;
* текст;
* ссылки;
* изображения;
* таблицы;
* формы;
* видео и аудио.

HTML отвечает за **содержание и структуру страницы**, а не за программную логику.

---

## 📁 Структура проекта

```text
project/
├── index.html
├── about.html
├── images/
│   └── cat.jpg
└── media/
    └── temp_video.mp4
```

* `index.html` — главная страница;
* `about.html` — дополнительная страница;
* `images/` — изображения;
* `media/` — видео и аудио.

---

## 🧱 Базовая структура HTML-документа

```html
<!DOCTYPE html>
<html lang="ru">
    <head>
        <meta charset="UTF-8">
        <title>Блог о путешествиях</title>
    </head>

    <body>
        <h1>Привет, мир!</h1>
    </body>
</html>
```

### Основные элементы

| Элемент                  | Назначение                        |
| ------------------------ | --------------------------------- |
| `<!DOCTYPE html>`        | Указывает современную версию HTML |
| `<html>`                 | Корневой элемент страницы         |
| `lang="ru"`              | Язык содержимого страницы         |
| `<head>`                 | Служебная информация              |
| `<meta charset="UTF-8">` | Кодировка страницы                |
| `<title>`                | Название вкладки браузера         |
| `<body>`                 | Видимое содержимое страницы       |

---

## 🏷️ HTML-теги

Большинство тегов имеют открывающую и закрывающую части:

```html
<p>Текст абзаца</p>
```

Некоторые теги не содержат вложенного текста:

```html
<img src="images/cat.jpg" alt="Кот">
<input type="text">
<br>
<hr>
```

---

## 📰 Заголовки и текст

### Заголовки

```html
<h1>Главный заголовок</h1>
<h2>Заголовок раздела</h2>
<h3>Заголовок подраздела</h3>
```

Заголовки доступны от `<h1>` до `<h6>`.

Обычно `<h1>` используется для главного заголовка страницы.

### Абзац

```html
<p>Это обычный текстовый абзац.</p>
```

### Перенос строки

```html
<br>
```

### Горизонтальная линия

```html
<hr>
```

---

## 💬 Цитаты

```html
<blockquote>
    Текст большой цитаты.
</blockquote>

<p>Автор цитаты: <cite>Боб Иванов</cite></p>
```

* `<blockquote>` — отдельный блок с цитатой;
* `<cite>` — автор или источник цитаты.

---

## 💬 Комментарии

Комментарии не отображаются на странице:

```html
<!-- Этот текст виден только в HTML-коде -->
```

Можно временно отключить элемент:

```html
<!-- <h3>Скрытый заголовок</h3> -->
```

## 📋 Списки

### Маркированный список

```html
<ul>
    <li>Главная</li>
    <li>Путешествия</li>
    <li>Контакты</li>
</ul>
```

### Нумерованный список

```html
<ol>
    <li>Москва</li>
    <li>Сочи</li>
    <li>Санкт-Петербург</li>
</ol>
```

* `<ul>` — маркированный список;
* `<ol>` — нумерованный список;
* `<li>` — элемент списка.

## 🔗 Ссылки

### Ссылка на другую страницу

```html
<a href="about.html">О нас</a>
```

### Ссылка на внешний сайт

```html
<a href="https://google.com" target="_blank">Google</a>
```

`target="_blank"` открывает ссылку в новой вкладке.

### Ссылка на раздел текущей страницы

```html
<a href="#travel">Путешествия</a>
```

Раздел должен иметь соответствующий `id`:

```html
<article id="travel">
    <h2>Путешествие на Байкал</h2>
</article>
```

### Временная ссылка

```html
<a href="#">Контакты</a>
```

## 🧭 Навигация

```html
<nav>
    <ul>
        <li><a href="index.html">Главная</a></li>
        <li><a href="#travel">Путешествия</a></li>
        <li><a href="#nature">Природа</a></li>
        <li><a href="about.html">О нас</a></li>
    </ul>
</nav>
```

Тег `<nav>` используется для основного блока навигации.

## 🖼️ Изображения

### Локальное изображение

```html
<img
    src="images/cat.jpg"
    alt="Кот"
    width="800"
>
```

### Изображение из интернета

```html
<img
    src="https://example.com/image.jpg"
    alt="Пейзаж"
    width="700"
    height="700"
>
```

### Основные атрибуты

| Атрибут  | Назначение         |
| -------- | ------------------ |
| `src`    | Путь к изображению |
| `alt`    | Текстовое описание |
| `width`  | Ширина             |
| `height` | Высота             |

Атрибут `alt` желательно заполнять для каждого изображения.

---

## 🎬 Видео и аудио

### Видео

```html
<video src="media/temp_video.mp4" controls width="500"></video>
```

### Аудио

```html
<audio src="media/audio.mp3" controls></audio>
```

Атрибут `controls` добавляет кнопки запуска, паузы и управления громкостью.

---

## 📺 Встраивание YouTube

```html
<iframe
    width="560"
    height="315"
    src="https://www.youtube.com/embed/VIDEO_ID"
    title="YouTube video player"
    allowfullscreen>
</iframe>
```

Тег `<iframe>` позволяет встроить на страницу содержимое другого сайта.

## 📊 Таблицы

```html
<table>
    <caption>Топ-3 города</caption>

    <tr>
        <th>Место</th>
        <th>Город</th>
        <th>Страна</th>
    </tr>

    <tr>
        <td>1</td>
        <td>Москва</td>
        <td>Россия</td>
    </tr>

    <tr>
        <td>2</td>
        <td>Сочи</td>
        <td>Россия</td>
    </tr>
</table>
```

| Тег         | Назначение          |
| ----------- | ------------------- |
| `<table>`   | Таблица             |
| `<caption>` | Заголовок таблицы   |
| `<tr>`      | Строка              |
| `<th>`      | Заголовочная ячейка |
| `<td>`      | Обычная ячейка      |

## 📝 Формы

```html
<form action="about.html" method="post">
    <label for="name">Введите имя:</label>
    <input type="text" id="name" name="user_name">

    <br>

    <label for="email">Введите почту:</label>
    <input type="email" id="email" name="user_email">

    <br>

    <label for="message">Введите сообщение:</label>
    <textarea
        id="message"
        name="user_message"
        rows="10">
    </textarea>

    <br>

    <label for="password">Введите пароль:</label>
    <input
        type="password"
        id="password"
        name="user_password">

    <br>

    <button type="submit">Отправить</button>
</form>
```

### Основные элементы формы

| Элемент      | Назначение          |
| ------------ | ------------------- |
| `<form>`     | Форма               |
| `<label>`    | Подпись поля        |
| `<input>`    | Поле ввода          |
| `<textarea>` | Многострочный текст |
| `<button>`   | Кнопка              |

### Типы полей

```html
<input type="text">
<input type="email">
<input type="password">
```

### Важные атрибуты формы

| Атрибут  | Назначение              |
| -------- | ----------------------- |
| `action` | Адрес отправки формы    |
| `method` | HTTP-метод отправки     |
| `id`     | Идентификатор элемента  |
| `name`   | Имя отправляемого поля  |
| `for`    | Связь `<label>` с полем |
| `type`   | Тип поля                |

Значение `for` у `<label>` должно совпадать с `id` соответствующего поля:

```html
<label for="email">Почта:</label>
<input type="email" id="email" name="user_email">
```

## 🧩 Семантические теги

```html
<body>
    <header>
        <nav>Навигация</nav>
        <h1>Блог о путешествиях</h1>
    </header>

    <main>
        <article>
            <h2>Путешествие на Байкал</h2>
            <p>Описание путешествия.</p>
        </article>
    </main>

    <footer>
        <p>&copy; 2026 Блог о путешествиях</p>
    </footer>
</body>
```

| Тег         | Назначение               |
| ----------- | ------------------------ |
| `<header>`  | Верхняя часть страницы   |
| `<nav>`     | Навигация                |
| `<main>`    | Основное содержимое      |
| `<article>` | Самостоятельный материал |
| `<footer>`  | Нижняя часть страницы    |

Семантические теги помогают понятнее описывать структуру страницы.

## ⚙️ Атрибуты HTML

Атрибуты указываются внутри открывающего тега:

```html
<a href="about.html" target="_blank">О нас</a>
```

Примеры атрибутов:

```html
lang="ru"
href="about.html"
src="images/cat.jpg"
alt="Кот"
id="travel"
class="article"
width="800"
controls
```

Один элемент может содержать несколько атрибутов.

---

## 🔣 Специальные символы

Знак авторского права:

```html
&copy;
```

Результат:

```text
©
```

Пример:

```html
<footer>
    <p>&copy; 2026 Блог о путешествиях</p>
</footer>
```

```html
<!DOCTYPE html>
<html lang="ru">
    <head>
        <meta charset="UTF-8">

            <article id="travel">

                <img
                    src="images/cat.jpg"

                    width="500">

                <p>Описание путешествия.</p>
            </article>
        </main>

        <footer>
            <p>&copy; 2026 Блог о путешествиях</p>
        </footer>
    </body>
</html>
```

---

## ⚠️ Важные моменты

* HTML-файл обычно имеет расширение `.html`.
* Главная страница проекта часто называется `index.html`.
* Теги должны быть правильно вложены друг в друга.
* Значение `href="#travel"` ссылается на элемент с `id="travel"`.
* Путь `images/cat.jpg` считается относительно текущего HTML-файла.
* Для изображений следует указывать атрибут `alt`.
* У полей формы атрибут `name` определяет имя отправляемого значения.
* Семантические теги делают структуру страницы понятнее.
* HTML-формы далее можно обрабатывать на сервере с помощью FastAPI или Django.
