# 🐍 Базовые типы данных Python

На занятии разобрали основные типы данных:

```text
int
float
str
bool
None
```

Проверить тип объекта можно с помощью:

```python
type()
```

Например:

```python
x = 10

print(type(x))
```

Результат:

```text
<class 'int'>
```

---

# 🔢 `int` — целые числа

`int` используется для хранения целых чисел:

```python
age = 27
year = 2027
temp = -7
```

Это могут быть:

```python
x = 1
x = -100
x = 0
```

Проверяем тип:

```python
x = 1

print(type(x))
```

Результат:

```text
<class 'int'>
```

# ➕ Арифметические операции

Пусть есть два числа:

```python
x = 17
y = 5
```

## Сложение `+`

```python
print(x + y)
```

```text
22
```

## Вычитание `-`

```python
print(x - y)
```

```text
12
```

## Умножение `*`

```python
print(x * y)
```

```text
85
```

## Обычное деление `/`

```python
print(x / y)
```

```text
3.4
```

Важно: оператор `/` возвращает `float`, даже если числа делятся без остатка:

```python
x = 20
y = 5

res = x / y

print(res)
print(type(res))
```

Результат:

```text
4.0
<class 'float'>
```

# 🔄 Преобразование типов

Тип одного значения можно преобразовать в другой.

Например:

```python
res = 2027 / 27

print(res)
print(type(res))
```

Получим `float`.

Преобразуем в `int`:

```python
new_res = int(res)
```

# `int()` и дробные числа

Например:

```python
res = int(1.97)

print(res)
```

Результат:

```text
1
```

`int()` не округляет число, а отбрасывает дробную часть.

---

# ⚠️ Не любую строку можно преобразовать в `int`

Так работает:

```python
res = int("1")

print(res)
```

Результат:

```text
1
```

А так:

```python
int("1.97")
```

не работает.

Python получит ошибку:

```text
ValueError
```

Потому что строка `"1.97"` не является записью целого числа.

Если необходимо преобразовать такую строку:

```python
num = float("1.97")
```

Сначала получаем:

```text
1.97
```

# 🎯 `round()` — округление

Есть число:

```python
res = 12345.6789
```

Можно округлить:

```python
print(round(res))
```

Результат будет целым по значению:

```text
12346
```

---

Можно указать количество знаков после точки:

```python
print(round(res, 2))
```

Результат:

```text
12345.68
```

---

Можно округлять и до десятков или сотен:

```python
print(round(res, -2))
```

Результат:

```text
12300.0
```

# 🏷️ Подсказки типов

В Python можно указать предполагаемый тип переменной:

```python
x: int = 1
y: float = 1.0
```

Это называется аннотацией типа.

```python
x: int = 1
```

означает:

> предполагается, что `x` содержит `int`.

Но Python не запрещает записать туда другой тип:

```python
x: int = "hello"

print(type(x))
```

Результат:

```text
<class 'str'>
```

То есть аннотация:

```python
x: int
```

не выполняет автоматическое преобразование и сама по себе не запрещает другой тип.

---

# 🔄 Тип переменной может меняться

Python использует динамическую типизацию.

Например:

```python
x = 1
x = "qaz"
```

Сначала `x` ссылается на объект типа:

```text
int
```

затем:

```text
str
```

# ⌨️ `input()`

Функция:

```python
input()
```

используется для получения данных от пользователя.

Например:

```python
age = input("Please input your age: ")

print(age)
print(type(age))
```

Важно:

> `input()` всегда возвращает строку `str`.

Даже если пользователь введёт:

```text
30
```

тип будет:

```text
str
```

---

Поэтому так сделать нельзя:

```python
age = input("Please input your age: ")

res = age + 1
```

Потому что Python пытается сложить:

```text
str + int
```

---

Нужно преобразовать строку:

```python
age = input("Please input your age: ")
age = int(age)

res = age + 1

print(res)
```

Или сразу:

```python
age = int(input("Please input your age: "))

print(age + 1)
```

---

# 🧠 `type()` и `id()` после преобразования

Например:

```python
age = input("Please input your age: ")

print(type(age))
print(id(age))

age = int(age)

print(type(age))
print(id(age))
```

После преобразования создаётся значение другого типа, поэтому изменяются:

```text
type
id
```

# ⚖️ Операторы сравнения

Пусть:

```python
a = 17
b = 12
```

Можно сравнивать значения:

```python
a == b
a != b
a < b
a <= b
a > b
a >= b
```

Обозначения:

```text
==  равно
!=  не равно
<   меньше
<=  меньше или равно
>   больше
>=  больше или равно
```

Например:

```python
print(a > b)
```

Результат:

```text
True
```

Результатом сравнения является тип:

```text
bool
```

# 🧮 Порядок выполнения операций

Как и в обычной математике, операции имеют приоритет.

Например:

```python
res = (2 + 2) * 2 ** 2

print(res)
```

Сначала:

```text
(2 + 2)
```

затем:

```text
2 ** 2
```

затем умножение.

Результат:

```text
16
```

Скобки позволяют явно задать порядок вычислений.

# 🔄 Преобразование в `float`

Из `int`:

```python

```


# ➕ Операции с `float`

Для `float` доступны те же основные арифметические операторы:

```python

print(num_1 + num_2)
print(num_1 - num_2)
print(num_1 * num_2)

print(num_1 % num_2)
```

```python
print(round(0.1 + 0.2, 2))
```

# 💰 `Decimal`

Если требуется более точная работа с десятичными значениями, существует `Decimal`.

```python
from decimal import Decimal
```

```python
a = Decimal("0.1")

res = a + b

print(res)
```

```text

```

Для `Decimal` удобно передавать значение строкой:

```python
Decimal("0.1")
```

# 🛠️ Методы строк

Пусть есть строка:

```python
text = "heLlO woRld"
```

## `capitalize()`

Первый символ делает заглавным:

```python
print(text.capitalize())
```

```text
Hello world
```

---

## `lower()`

Переводит символы в нижний регистр:

```python
print(text.lower())
```

```text
hello world
```

---

## `upper()`

Переводит символы в верхний регистр:

```python
print(text.upper())
```

```text
HELLO WORLD
```

---

## `title()`

Каждое слово начинается с заглавной буквы:

```python
print(text.title())
```

```text
Hello World
```

---

## `replace()`

Заменяет часть строки:

```python
print(text.replace("h", "123"))
```

Например:

```text
123eLlO woRld
```

---

# ⚠️ Строки не изменяются сами

Например:

```python
text = "heLlO woRld"

print(text.upper())
print(text)
```

`upper()` возвращает новую строку.

Исходная строка остаётся:

```text
heLlO woRld
```

Чтобы сохранить результат:

```python
text = text.upper()
```

# `\` в строках

```python
path = "c:\\User\\Python"
```

# ⭕ `None`

`None` означает отсутствие значения.

Например:

```python
res = None

print(res)
print(type(res))
```

Результат:

```text
None
<class 'NoneType'>
```

---

`None` — это не пустая строка.

```python

```

и:

```python

```

это разные значения.

У них разные типы:

```text
None  → NoneType
""    → str
```
